# ADR-0001：首期使用 SwiftUI 原生 iOS

## 状态

已接受

## 背景

首期产品需要相机、文件、推送、离线记录和分娩应急信息等原生能力，并且当前只确定首发 iOS。

## 决策

首期使用 SwiftUI 原生开发 iOS App，不同期建设 Android 或跨平台客户端。

## 影响

- 可以针对 iOS 做完整体验和关键离线能力；
- Android 后续需另行建设客户端；
- 核心业务和 Agent 能力必须放在服务端，避免与 iOS 绑定。

## 备选方案

- 跨平台：首期不需要同时覆盖多个平台，因此不采用；
- Web App：不适合当前原生能力和分娩场景要求。
