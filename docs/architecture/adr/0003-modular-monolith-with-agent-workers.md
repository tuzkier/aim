# ADR-0003：模块化单体配合 Agent 后台任务进程

## 状态

已被 [ADR-0011](0011-eve-independent-agent-runtime.md) 取代

## 背景

项目从空白开始，需要快速形成完整业务闭环，同时 Agent 存在耗时、定时和可重试的后台工作。

## 决策

核心业务采用模块化单体；Agent 耗时和主动任务由独立后台进程通过任务队列执行。

## 影响

- 业务开发、事务和排查保持直接；
- Agent 失败不会阻塞普通 API；
- 模块边界必须在代码层保持清楚；
- 暂不获得微服务的独立部署能力。

## 备选方案

- 微服务：当前团队和规模不值得承担分布式复杂度；
- 全部同步执行：模型耗时与失败会影响普通业务体验。
