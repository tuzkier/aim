# ADR-0005：结构化业务事实为唯一真相

## 状态

已接受

## 背景

健康档案、报告、任务、用户记录和 Agent 对话可能产生不同说法。若以模型记忆为事实，会造成计划和医疗信息漂移。

## 决策

结构化业务数据是唯一事实来源。Agent 记忆只作为工作上下文，不得覆盖医生确认信息或用户确认内容。

事实优先级为：医生确认信息、用户确认信息、报告机器提取、Agent 推导、普通知识建议。

## 影响

- 报告原文、机器提取和已确认事实需要分开保存；
- 冲突生成待核实项；
- Agent 输出必须写回正式功能后才成为业务状态。

## 备选方案

- 依赖对话历史：难以验证、纠正和同步；
- 全量事件溯源：首期复杂度过高。
