# ADR-0008：首期采用必要安全底线

## 状态

已接受

## 背景

产品按真实用户和真实健康资料场景设计，但首期不应被复杂权限、审计和合规平台拖慢。

## 决策

首期实现独立账号、家庭隔离、孕妇健康资料本人控制、Agent 受控 Tool 执行、医疗边界、加密传输、退出与删除，以及重要修改查看和撤销。

首期不建设字段级权限、多级审批、复杂审计中心、完整数据导出平台或在线医疗介入。

## 影响

- 保留必要安全底线；
- 权限体验和运营后台保持简单；
- 后续扩展前需要重新评估安全与合规要求。

## 备选方案

- 一开始建设完整安全平台：范围和成本过高；
- 仅按演示产品处理：不适合真实健康资料场景。
