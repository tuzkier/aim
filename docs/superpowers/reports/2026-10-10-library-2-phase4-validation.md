# AIM 记忆功能验收记录

日期：2026-10-10。功能分支：`dev/library-phase4-memory`，从本地 `development` 的 `36f1ee3` 开始。

## 已实现

- 新增 `memory` 记录，六类稳定事实；一句话去两侧空白后 1–80 字，标题自动生成。手动新增与 AIM 使用同一套校验和授权。
- 每家庭最多 50 条有效记忆，包含私有记忆。创建时锁家庭行再计数；并发第 50 条只允许其中一个请求成功，删除后可重新添加。
- `remember` 直接执行，支持工具幂等和整条撤销；`forget_memory` 先审批，限定 memory 类型，不能作为删除其他记录的入口。
- `/internal/agent-tools/list-memories` 只返回当前孕期、当前成员可见的记忆，沿用家庭成员与孕期归属验证。
- 每轮开始重新读取记忆，包括会话第一轮。Eve 的 session 指令会长期驻留，故不用它存事实快照；当轮读失败返回 null，不阻断会话，不把事实或 token 写入失败日志。
- 注入的事实携带来源成员，当前对话账号来自已验证的 auth；未写明主体的个人事实只用于来源成员，明确写明主体的内容按原文理解。记忆作为 JSON 数据，不允许改变指令或授权边界。
- 网页的已记住卡、直接撤销按钮、遗忘确认卡、原生查看以及写入后的刷新已接通。卡片在成功前不显示已记住。
- iOS 资料库新增记忆卡与按类别分组的管理页；新增、编辑、删除确认、作者可见性开关、问 AIM 和原生记忆详情均已接通。未知类别保留原文，需要选择有效类别才能保存。
- 家庭记忆家人可编辑；私有记忆只对作者可见、可改；可见范围仅作者可改。

## 边界

- 记忆属于当前孕期，不自动继承到其他孕期；50 条上限按家庭计算。删除记忆停止后续读取，不删除既有聊天记录。
- 读取失败不阻断对话，但不会声称已经取得完整记忆。授权隔离由 API 两账号测试证明，不能用一次模型回复代替权限检查。
- 本轮只更新本地栈；没有推送、发布 TestFlight 或部署生产环境。
