# 页面风格统一 设计规格

2026-10-08

## 1. 目标

以新首页为基准，让四个标签页（首页、待办、资料库、家庭）看起来是同一个 App。只换外观，不动功能和数据。

## 2. 规则

### 2.1 标签页顶部（`AimPageHeader`）

- 结构：灰色小字说明（`.caption`，`aimTextSecondary`）+ 标题（`.title` 加粗，`aimTextPrimary`）+ 右侧圆形按钮。
- 各页的说明文字：首页是日期（「10月8日 星期四」），标题是问候；待办页是日期，标题「待办」，可点进完整时间线；资料库是「已收录 N 条」；家庭页是「N 位家人」。
- 系统导航栏一律隐藏。
- 页面左右边距 16 点，顶部不再额外留白。

### 2.2 圆形按钮（`AimCircleButton` / `AimCircleIcon`）

- 34 点（`AimMetrics.circleButtonSize`），随动态字号缩放。
- AIM 入口用强调色浅底（`tinted`）；其余用卡片底色加细边框。

### 2.3 卡片

- 一律用现有的 `.aimCard()`：`aimSurface` 底色、1 点 `aimSeparator` 描边、20 点圆角、16 点内边距。
- 卡片标题用 `.aimSectionTitle()`（`.headline`，`aimTextPrimary`）。
- 卡片里的多行用 `.cardRow()`（上下 12 点，整行可点），行间用 `aimSeparator` 色的分隔线。

### 2.4 长列表

- 待办页的今天、接下来 7 天、最近记录保留现在的列表排法（滑动操作、点击高亮），只把分组标题换成 `.aimSectionTitle()`。

### 2.5 二级页面

- 个人资料、成员详情、本周详情、记录详情、待办详情保留系统居中标题和返回按钮，不改。

## 3. 涉及的改动

- 新增 `Core/DesignSystem/Components/AimPageHeader.swift`（顶部、圆形按钮、卡片标题样式）。
- 首页：顶部换成公共组件，卡片改用 `.aimCard()`。
- 待办页：`HomeHeader` 换成公共组件，说明文字由强调色改为灰色；分组标题加粗。
- 资料库：顶部换成公共组件，说明文字移到标题上方。
- 家庭页：由系统分组列表改为卡片布局，家庭动态改为卡片并按需加载。
