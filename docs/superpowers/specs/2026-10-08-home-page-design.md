# 首页 设计规格

2026-10-08

## 1. 目标

App 现在把「孕期」标签（以待办为主）当首页。新做一个真正的首页：第一屏回答「今天孕几周、宝宝多大、还有多久见面」，再给出这周的变化、今天要做的事、最常用的入口、家里的动静和安全提示。原「孕期」页改名「待办」，内容不变。

不做：AI 生成的每日简报、插画、产后阶段、按天变化的内容。

## 2. 页面

### 2.1 标签栏

「首页、待办、AIM、资料库、家庭」五个，启动默认首页。图标：`house`、`checklist`、`wand.and.sparkles`（沿用）、`books.vertical`（沿用）、`person.2`（沿用）。

### 2.2 首页（自上而下）

1. **顶部**：日期（「10月8日 周三」）+ 问候（5–11 点早上好，11–13 点中午好，13–18 点下午好，其余晚上好）+ 称呼（家里的称呼，未设置用身份名）。右侧：家人头像叠放（最多 3 个，点去家庭标签）、AIM 圆形按钮（切到 AIM 标签）。
2. **孕周主卡**：左侧进度圆环（已过天数 ÷ 280，超过按满），环内是本周水果 emoji 和「像一个椰子」；右侧阶段标签（孕早期 0–13 周、孕中期 14–27 周、孕晚期 28 周起）、「31 周 +1 天」、「约 41 厘米 · 1.5 公斤」、「距预产期 62 天」（过了预产期显示「已过预产期 N 天」）。底部三段条表示所在阶段及阶段内进度。点击进本周详情。
3. **这一周**：三行——宝宝、妈妈、提示（取本周建议的第一条）。点击进本周详情。
4. **今天**：今天到期与已逾期的未完成待办，逾期在前，最多 3 项；可勾选完成（沿用现有完成与撤销提示）；右侧显示负责人称呼（指派给别人时）或「已逾期」（红色）。标题行「今天」+「全部 N 项 ›」（切到待办标签）。没有时显示「今天没有安排」，若有将来的待办再加一行「下一件：10月12日 产检复查」。
5. **快捷入口**（四个）：
   - 记一笔：打开新增记录面板（`RecordComposerView`）。
   - 拍报告：弹出系统选择（拍照 / 从相册选，单张），选好后切到 AIM 标签，并把这张图放进 AIM 输入框的待发图片里（网页提供 `window.__aimAttachImage__(dataURL)`，内部走现有的图片适配器：压缩、发送时上传）。
   - 体重血压：打开新增记录面板，类型预选「产检」。
   - 问 AIM：切到 AIM 标签。
6. **家里最近**：家庭动态最新两条（沿用家庭页的句子与图标），点击切到家庭标签。家里只有自己一人时换成「邀请家人一起」卡片，点击打开邀请面板。
7. **安全提示条**：「出血、破水、胎动明显减少——立即就医」，危险色底，不可关闭，点击打开资料库的危险信号分类页。

每块独立加载；某块失败只在该块内显示「加载失败，点这里重试」。进入首页、下拉刷新、收到 `aimDataChanged` 时重新加载。

### 2.3 本周详情

- 顶部周数切换：「‹ 30 · 31 周 · 32 ›」，可左右翻到第 4–42 周；当前周下方注明「这是你现在所在的一周」。
- 大号 emoji、「宝宝像一个椰子」、「身长约 41 厘米 · 体重约 1.5 公斤」。
- 三块：宝宝、妈妈、这周可以做（2–3 条）。每条建议右侧「加进待办」，点后新建一条同名待办并提示「已加进待办」。
- 「关于这一周，问问 AIM」：切到 AIM 并自动发送「我现在孕 31 周，这周需要注意什么？」（沿用现有「打开即发送」机制）。
- 页脚：来源与核对日期；「数值为平均水平，个体差异很大，以产检结果为准。约 20 周前为头臀长，之后为头脚长。」

### 2.4 待办标签（原「孕期」页）

内容与行为不变（今天、接下来 7 天、最近记录、时间线）。去掉顶部大号孕周标题，换成普通导航标题「待办」，右上角保留「+」菜单与 AIM 按钮。

### 2.5 小屏

iPhone SE 宽度下圆环由 112 缩到 88 点，第一屏至少露出完整主卡与「这一周」标题。

## 3. 孕周内容

- 新集合 `content/weekly/weeks.yaml`（含 `schema.json`），第 4–42 周每周一条：`week`、`fruit`（emoji）、`fruit_name`（「椰子」）、`length_cm`、`weight_g`（早期可空）、`baby`、`mom`、`tips`（2–3 条）。文件头有 `source`、`source_url`、`reviewed_at`。
- 文字每段 1–2 句，平实、不吓人、不下诊断；与产检有关的写「按医生安排」。
- 4 周以前：本周详情与主卡用通用文字「宝宝刚开始发育，按时做早孕检查」，不显示身长体重。42 周以后按第 42 周显示，主卡写「已过预产期」，提示「留意产兆，按医生安排及时就医」。
- 接口 `GET /api/v1/content/weekly`：一次返回全部周（约 40 条），App 缓存到本地，启动时用缓存先显示、后台刷新。
- 来源：国家卫生健康委员会公开的孕产期保健资料，以及公开的孕周发育参考（身长体重取常见参考值的中位数并取整）。

## 4. App 结构

- 新文件（`project.pbxproj` 手工登记）：
  - `Features/Home/HomeDashboardView.swift`：首页整页与各块。
  - `Features/Home/HomeDashboardStore.swift`：首页数据（孕期、本周内容、今天的待办、家庭动态）。
  - `Features/Home/WeekDetailView.swift`：本周详情。
  - `Features/Home/WeeklyContent.swift`：孕周内容模型、缓存、按周查找、阶段与进度计算。
- `App/AimApp.swift`：五个标签，默认首页；首页与各标签之间的跳转（切标签、带图进 AIM）。
- 现有 `HomeView`（待办页）：标题改为「待办」，去掉大孕周头部。
- AIM 网页 `apps/agent-web`：`window.__aimAttachImage__(dataURL)`，把图片加进输入框待发列表。
- 首页数据复用现有接口：`/pregnancies/{id}`、`/plan`、家庭动态、家庭详情；新增只有 `GET /api/v1/content/weekly`。

## 5. 测试

- 后端：孕周内容接口返回 39 条、周数连续 4–42、每条字段齐全；内容文件通过 schema 校验。
- App 单元：阶段划分与进度（0、13、14、27、28、40、45 周）；4 周以前与 42 周以后的回退；今天的待办筛选与排序（逾期在前、最多 3 项、下一件）；问候时段；内容缓存读写。
- 网页单元：`__aimAttachImage__` 把 dataURL 变成待发图片。
- UI：启动停在首页；主卡点开本周详情并能翻周；「全部 N 项」切到待办；快捷入口「记一笔」打开新增记录；原有经由「孕期」标签的用例改为「待办」标签。
