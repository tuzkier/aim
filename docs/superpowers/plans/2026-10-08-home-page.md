# 首页 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 新增真正的首页（孕周主卡、这一周、今天、快捷入口、家里最近、安全提示）与本周详情页，原「孕期」页改为「待办」标签。

**做法：** 孕周内容写成仓库内容库的一类新集合，经一个只读接口整份下发、App 本地缓存；首页数据复用现有接口与各 Store；「拍报告」由原生选图后通过网页暴露的 `__aimAttachImage__` 放进 AIM 输入框。

**技术栈：** FastAPI + YAML 内容库；SwiftUI；React（agent-web）。

**规格：** `docs/superpowers/specs/2026-10-08-home-page-design.md`

## 全局约束

- 文案一律简体中文；孕周内容每段 1–2 句、不下诊断，与检查相关的写「按医生安排」。
- 阶段：孕早期 0–13 周，孕中期 14–27 周，孕晚期 28 周起；进度 = 已过天数 ÷ 280，封顶 1。
- 孕周内容范围第 4–42 周，共 39 条；4 周以前用通用文字，42 周以后按第 42 周并提示已过预产期。
- 标签：首页（`house`）、待办（`checklist`）、AIM、资料库、家庭；启动默认首页。
- iOS 新文件只有 `HomeDashboardView.swift`、`HomeDashboardStore.swift`、`WeekDetailView.swift`、`WeeklyContent.swift` 与测试 `HomeDashboardTests.swift`，均在 `project.pbxproj` 四处登记（编号从 149 起）。

- [ ] **Step 1：测试**（`tests/integration/test_weekly_content.py`）

```python
from fastapi.testclient import TestClient
from aim_api.bootstrap import create_app

def test_weekly_content_covers_weeks_4_to_42() -> None:
    with TestClient(create_app()) as client:
        body = client.get("/api/v1/content/weekly").json()
    weeks = body["weeks"]
    assert [w["week"] for w in weeks] == list(range(4, 43))
    for w in weeks:
        assert w["fruit"] and w["fruit_name"] and w["baby"] and w["mom"]
        assert 1 <= len(w["tips"]) <= 3
        assert w["length_cm"] is None or w["length_cm"] > 0
    assert body["reviewed_at"] and body["source"]
```
